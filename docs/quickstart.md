## Quickstart

This Quickstart targets Solidity/Ethereum and TypeScript/ethers. You'll run a local chain with Anvil and execute a minimal interaction.

### Prerequisites
- Node.js (LTS) and a package manager (pnpm or yarn)
- Foundry (forge, anvil)

### Steps
1. Start a local chain:
```bash
anvil
```
2. Install dependencies:
```bash
pnpm install   # or: yarn install
```
3. Build and test contracts:
```bash
forge build && forge test
```
4. Run an example script (TypeScript):
```bash
node examples/your-example.js   # placeholder
```

Next: read the Architecture and Ethereum pages for more depth.
